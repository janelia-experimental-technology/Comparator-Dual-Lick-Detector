# Comparator Dual Lick Detector
Mouse lick detector 

This design detects lick port licks using a method from:

A low-cost solution to measure mouse licking in an
electrophysiological setup with a standard analog-to-digital
converter

Abdallah Hayar, Jeri L. Bryant, John D. Boughter, and Detlef H. Heck*

A comparator is used in lieu of the ADC to create a simple circuit that outputs TTL levels.

The circuit can be built with or without electrical isolation.
